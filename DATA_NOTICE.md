# Data notice

The full evaluation inputs are not copied into this GitHub staging folder pending confirmation of redistribution rights. The analysis harnesses expect the following local files:

- `server/data/model-registry.json` — frozen registry and metric observations.
- `scratch/arena_snapshot_2026-10-08.json` — Agent Arena headline snapshot.
- `scratch/arena_full_2026-10-02.json` — earlier snapshot used in sensitivity analysis.

The registry includes benchmark-derived fields, including Artificial Analysis measurements. Generated JSON tables and logs are also omitted because they contain cohort-level results derived from these sources. Obtain permission or replace the inputs with redistributable sources before adding them to a public repository. The manuscript currently reports the aggregate statistics, but those statistics do not replace the missing machine-readable inputs.
